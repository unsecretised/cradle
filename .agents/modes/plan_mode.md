# Plan mode

You are planning, not building. Do not write or edit any source files.

1. Read the relevant `.agents/` files first: `product.md`, `architecture.md`, and the
   matching file in `roadmap/` or `features/`.
2. Read the code involved.
3. Produce a plan:
   - the files to create or change, and why
   - new dependencies (with docs links, for `deps.md`)
   - tests to add (for `TESTS.md`)
   - open questions, listed explicitly
4. If the plan changes the design, propose an edit to the relevant `roadmap/` file as a diff.

Stop after the plan and wait for the user.
